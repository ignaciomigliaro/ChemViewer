# ChemViewer 0.8.0 — NEB-TS reaction profiles

Open an ORCA output, then Tools → Energy Landscape (or the chart toolbar button). When a complete NEB summary is detected, **NEB reaction profile** is selected automatically. Its default view is the reactant/refined-TS/product reaction diagram, referenced to reactants in kcal/mol, with green horizontal levels, dashed connections, numeric energies and matching structures above the levels. Choose **All NEB images + refined TS** for the full summary path and **PES / line profile** for continuous connecting lines. Clear the NEB checkbox to return to the Cartesian geometry/TS optimization energy history. **Markers** independently controls all data-point markers, including the former minimum highlight; turn it off for lines only and click Update plot. Connections, labels, structures, reference and units remain independently configurable.

The final path summary and optimization history are separate datasets. NEB rows are never associated with TS optimization geometries by list index. The parser prefers the last PATH SUMMARY, accepts the E(Eh)/dE(kcal/mol) headers with or without the distance column, retains source lines, distinguishes CI from TS, validates sequential image numbering and declared intermediate-image count where present, and rejects malformed/nonfinite/truncated tables. A malformed last summary does not silently reuse an earlier complete one. TS convergence is checked from its own summary context and displayed when unconfirmed. Ordinary NEB summaries without a refined TS support the all-images view without inventing a TS/barrier.

ORCA documents that NEB-TS first obtains a climbing image and then refines it with a separate TS optimization, followed by a final path summary: [official ORCA tutorial](https://www.faccts.de/docs/orca/6.1/tutorials/react/nebts.html). Consequently the refined **TS row**, rather than the largest CI/image energy, defines the forward/reverse activation barriers shown here. Full-band image energies can exceed the refined TS energy. Paths use schematic summary order; no arc-length coordinate or smoothing is invented.

## Scientific values and precision

Both rounded absolute Hartree energies and the printed relative kcal/mol column are retained. Relative NEB plots/barriers use that printed relative column directly, avoiding reconstruction from the more rounded Hartree column. Unit conversion is explicit. Absolute plots use the printed absolute Hartree column. Barriers are TS−reactant and TS−product; reaction energy is product−reactant. These are electronic ΔE/ΔE‡, not Gibbs ΔG/ΔG‡; no thermochemical corrections are fabricated.

In the supplied TS.out, the final summary contains 10 indexed images plus a distinct TS row. It reports forward ΔE‡ 86.35, reverse ΔE‡ 2.66 and reaction ΔE +83.69 kcal/mol. The CI is +92.90 kcal/mol and remains explicitly separate. These are the supplied calculation's values, not a general chemical reference or a verification of the underlying electronic-structure calculation.

## Structures and output

Optional companion files are read only from the opened output's basename: `_MEP_trj.xyz` and `_NEB-TS_converged.xyz`. They supply graphical structure thumbnails, never replacement energies. An image is matched by image index/count or explicit TS file, element/atom ordering, and explicit comment energy within the five-decimal summary rounding tolerance (5.5e−6 Eh). Mismatching/stale images are omitted; missing structures are marked rather than substituted with TS optimization frames. The supplied file has valid reactant, refined TS and product matches. These graphical structures use Paton-compatible colors and distance-inferred bonds.

Export retains PDF/SVG vectors, 600-dpi PNG, CSV, JSON and a standalone copy of the Matplotlib script. CSV/JSON record rounded Hartree and printed relative energies, labels, source lines and companion structure provenance. Metadata identify the energy basis, units, reference, explicit-TS barriers, marker setting and plot style. The calculation files are read-only and never rewritten.
